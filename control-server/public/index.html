Promote readiness

    Promote moves code only: the current source tree is built, activated through a new release directory and the symlink is flipped atomically. The prod database is dumped with pg_dump first and is never overwritten by beta data. Rollback only points prod back at the previous release.

    Reports arrive from every client, including the ones that never got as far as signing in. Tokens, passwords and keys are stripped before a row is written, identical reports are collapsed to one a minute, and rows are deleted once the retention window passes.
