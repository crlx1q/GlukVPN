# GlukVPN site — changelog

Версии сайта идут вместе с каналами приложения: `beta` — тестовый контур
(`beta-api.gluk.tech`), `prod` — боевой (`api.gluk.tech`). Канал переключается
одной строкой в `assets/js/config.js` (`api.channel`).

## 0.3.0 — beta — 2026-08-22

### Аккаунт
- Вход по тому же контракту, что и в Flutter-клиенте: `POST /api/auth/login`,
  `POST /api/auth/refresh` с ротацией, `GET /api/auth/me`, `POST /api/auth/logout`.
- Новая страница `/login/`: форма входа, показ пароля, понятные ошибки
  (неверные данные, лимит попыток с обратным отсчётом, сервер недоступен),
  мини-кабинет после входа (подписка, устройства, публичный ID).
- В шапке справа: скелетон на время проверки сессии, дальше либо
  «Войти / Регистрация», либо чип аккаунта с меню и выходом.
- Токены: в памяти — только access, в localStorage — refresh с раздельными
  ключами по каналам (`gluk.beta.refresh` / `gluk.prod.refresh`). Пароль не хранится.
- Регистрация в состоянии «по приглашению»: на сервере
  `selfRegistrationEnabled = false` и эндпоинта регистрации нет.

### Маршруты
- Превью приложения переехало с `/app/` на `/mobile/`.
- `/app/` и `/account/` освобождены под будущий веб-кабинет.
- Добавлен `/login/`. Обновлён `sitemap.xml`.

### Интерфейс
- Глобус: фоновая симуляция коннектов — 24 города, постоянные дуги к узлам,
  разная скорость и цвет пакетов.
- Новые блоки на главной: бегущая строка технологий, метрики со счётчиками,
  живой тикер по регионам.
- Микро-анимации: блик под курсором на карточках, магнитная CTA,
  прогресс чтения на юридических страницах. Всё глушится при
  `prefers-reduced-motion: reduce`.
- Мобильное меню: закрывается по клику мимо кнопки, по фону, по Escape,
  по жесту «назад» и при ресайзе; иконка переключается на крест.
- Экраны приложения разнесены, третий телефон скрывается на узких экранах.
- Иконки платформ — официальные глифы (Android, Google Play, Windows, Apple,
  Telegram, Chrome).
- Исправлены битые символы в текстах (U+FFFD больше нет ни на одной
  странице).
- В подвале: `made by crlx1q` → https://crlx1q.com.

### Загрузки
- Добавлено расширение для Chrome в статусе Coming soon.
- Android — единственная активная сборка; Google Play, Windows, iOS, macOS — Coming soon.

### Шрифты (временно, только в бете)
- Панель выбора шрифта: Inter, Manrope, Onest, Golos Text, Geologica, Unbounded
  и системный. Выбор сохраняется в localStorage, также работает `?font=onest`.
- На релизе: `ui.fontPicker = false` и `ui.channelBadge = false` в `config.js`.

### Для деплоя
- Сайт — чистая статика без сборки и без внешних зависимостей.
- Конфиг nginx: `site/deploy/nginx-vpn.gluk.tech.conf`.
- На бета-сервере нужен `CORS_ALLOWED_ORIGINS=https://vpn.gluk.tech` (плюс
  `http://localhost:8080` для локальных тестов) и перезапуск сервиса:
  без этого браузер не сможет вызывать API (Flutter это не затрагивает).
